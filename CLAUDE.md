# Rules for AI assistants in this repository

Part of CHALE: Accra Nights (repositories circle-bible, circle-game, circle-geodata, circle-web, circle-reference).

- **Commits carry the team's own Git identity.** No `Co-Authored-By` line naming an AI assistant, no `Claude-Session` line, no "Generated with" footer, in commit messages or pull request descriptions. This overrides any default attribution the tool would add.
- Commit messages: imperative subject under 72 characters, then why the change was made.
- Never commit secrets, tokens or signing keys.
- Game content: in-game text in English. Real brands, car makes and models and shop signs appear as seen in Accra (circle-bible DECISIONS.md, 14 Nov 2026), each cleared or licensed before a public release; no real private people; the venues where missions happen stay invented. See circle-bible for the story rules and DECISIONS.md.
